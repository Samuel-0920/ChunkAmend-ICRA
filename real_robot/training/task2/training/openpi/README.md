# OpenPI source snapshot

This task-specific OpenPI source tree accompanies the UF850 training configuration. The upstream framework is [Physical Intelligence / OpenPI](https://github.com/Physical-Intelligence/openpi). Project additions include the UF850 observation/action adapter and registered task training configuration.

`pyproject.toml` and `uv.lock` retain the source snapshot's dependency resolution. Apache-2.0 and Gemma notices are retained alongside this file. Dataset payloads, caches, and training outputs are not included.
