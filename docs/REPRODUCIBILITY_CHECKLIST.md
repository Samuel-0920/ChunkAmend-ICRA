## 文件存放

Git 保存代码、小配置、锁定依赖、文档、清单与小型测试样例。权重、大数据集、完整日志和视频存到适合大文件的 Release 或数据托管，仓库保存可验证的下载清单。不要提交凭据、个人环境、缓存、临时文件。

## 发布前验收

1. 确认采用哪个仿真版本，保留其与真机 V004 的明确差异。
2. 移除机器专属绝对路径；机器人 IP 和相机绑定使用用户配置。不能把旧相机序列号当作通用默认。
3. 算法代码必须包含实际依赖，不上传仅能调用原作者本地路径的入口。
4. 独立复算示例轨迹，确保与对应历史统计口径一致。演示后来增加的平均 Jerk 不应冒充正式表中的 RMS。
5. 在新环境验证安装、模型载入、仿真测试；真机执行由具备相应硬件的操作者显式启动。
6. 说明完整训练复现、固定权重评估、仅表图复算这三种不同复现层级。
